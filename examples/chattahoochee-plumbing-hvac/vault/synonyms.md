# Counter shorthand

How contractors write and say things, and what each one means in the price book. If shorthand could mean two items, ask.

| They write | It means |
|---|---|
| cu, copper | hard copper pipe ([[price-copper]]) |
| 3/4 cu L, 3/4 L, 3/4 type L | type L hard copper pipe 3/4in |
| 1/2 M, 1/2 cu M | type M hard copper pipe 1/2in |
| 10' sticks, 10s | the 10 ft stick SKU |
| 20' sticks, 20s, full sticks | the 20 ft stick SKU |
| ell, ells, 90s | 90 degree elbows |
| CxC, sweat, swt | solder-joint (sweat) fitting or valve |
| MA, MIP adapter | male adapter |
| pex a 1/2 300 | PEX-A tubing 1/2in, 300 ft coil |
| pex b, crimp pex | PEX-B tubing |
| roll, coil | one PEX coil |
| crimp rings | copper crimp rings (PEX-B) |
| exp rings, expansion rings | expansion rings (PEX-A) |
| BV, ball valve | full-port brass ball valve |
| stops | quarter-turn angle stops |
| T&P | temperature and pressure relief valve |
| PRV | water pressure reducing valve |
| 40 gas, 50 gas, atmos | natural gas water heater, atmospheric vent |
| PV | power vent |
| exp tank, X-tank | thermal expansion tank |
| straight cool, AC + AH, cond + coil/AH | AC condenser and air handler (check [[price-hvac-equipment]] for a matched system) |
| 3 ton, 36k | 3 ton (36,000 BTU) |
| 410a, 410 | R-410A refrigerant |
| 454b, 454 | R-454B refrigerant |
| jug, tank (of refrigerant) | one full refrigerant cylinder |
| 50#, 50 lbs | 50 pounds |
| M8, M11, merv 8 | MERV 8, MERV 11 filter |
| contractor acct, our acct | contractor price level ([[price-levels]]) |
| TP, trade pro, pro pricing | Trade Pro price level ([[price-levels]]) |
