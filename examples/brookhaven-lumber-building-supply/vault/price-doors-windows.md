# Price book: doors and windows (USD each, list)

Only the hollow-core prehung interior doors are stocked. A prehung door must be ordered with a handing (left hand or right hand); if the request does not give one, ask. Exterior doors, solid-core doors, windows and patio doors are special order: the worker never prices them; send them to the millwork desk ([[special-orders]]). The list prices on special-order rows are for the millwork desk's reference only. No quantity break on doors and windows ([[quantity-breaks]]).
