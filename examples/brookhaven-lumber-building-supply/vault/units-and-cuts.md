# Units, board feet, pallets and cuts

- Unit is in the price book's Unit column: **pc** (one piece, at the length in the description), **bf** (per board foot), **sheet**, **ea** (each), **lb** (per pound), **box of N** (sold by the box only), **bag**, **pallet of N** (N bags on one pallet) and **lf** (per linear foot).
- Dimensional and treated lumber (pc): each length is its own SKU and is sold by the piece. A request with a size but no length (for example "60 2x6s") must be asked about. Never assume a length. We do not cut framing lumber.
- Board-foot species (bf): board feet = nominal thickness (in) x nominal width (in) x length (ft) / 12, per piece. 4/4 is 1 inch, 8/4 is 2 inches. A request in pieces must give thickness, width and length; multiply by the number of pieces, and round the line's board feet up to a whole board foot. A request in board feet is priced as asked.
- Sheet goods: by the whole sheet.
- Boxed fasteners (box of N): a request in pieces is converted to boxes (pieces / box size); if that is not a whole number, ask the customer. Boxes are never broken.
- Bulk nails (lb): by the whole pound.
- Bagged concrete, mortar and sand: a bag request for an item that has a pallet row is priced as whole pallets at the pallet row plus the remaining bags at the bag price, as two lines. A request for pallets is priced at the pallet row.
- Trim (lf): priced per linear foot and stocked in full lengths (the length is in the description). A request in sticks or lengths is converted to linear feet (sticks x stocked length). A linear-foot request that is not a whole number of stocked lengths is cut from a length. **Minimum cut: 2 feet**, whole feet only. **Cut charge: $2.00 per cut line**, added after the account level, never discounted.
- If a request gives no size, no length, no thickness, no quantity or (for prehung doors) no handing, ask. Never assume.
