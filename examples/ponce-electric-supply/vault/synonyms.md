# Synonyms: what customers write, and what we mean

The quote action rewrites the left column into the right column before it reads a request (longest phrase first; `-`, `/` and spaces are interchangeable, a trailing `s` is allowed). Several spellings go in one cell, separated by commas. Only write what the counter would read the same way every time; anything that could mean two items stays out, so the worker asks.

| Customers write | We mean |
|---|---|
| sp, single pole, 1p, 1 pole | 1-pole |
| 2p, double pole, two pole | 2-pole |
| breaker | plug-on breaker |
| nm, romex | NM-B |
| blk | black |
| wht | white |
| grn | green |
| 1/2 emt | EMT conduit 1/2in |
| 3/4 emt | EMT conduit 3/4in |
| 1/2 pvc | PVC schedule 40 conduit 1/2in |
| 3/4 pvc | PVC schedule 40 conduit 3/4in |
| 1g, single gang, one gang | 1-gang |
| 2g, double gang, two gang | 2-gang |
| recept, recep | receptacle |
| tr | tamper-resistant |
| wp | weatherproof |
| wire nut | twist-on wire connector |
| can retrofit, can light | LED retrofit downlight |
| exit/emergency combo, exit combo | LED exit sign and emergency light combo |
