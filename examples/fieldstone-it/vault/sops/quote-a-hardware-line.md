# SOP: price a hardware line

1. Find the SKU in [[hardware-price-list]]. If it is not there, stop: it is a special order for the service director.
2. Hardware part = quantity x unit price.
3. Apply the discount from [[volume-discounts]] to the hardware part only.
4. Setup part = quantity x setup fee per unit (never discounted).
5. Line total = discounted hardware part + setup part. Round to the cent.
6. If the line total is over $10,000, the quote needs the service director's approval ([[approvals]]).

Example: 12 x MON-27 = 12 x $289.00 = $3,468.00; less 4% = $3,329.28; setup 12 x $15.00 = $180.00; line total **$3,509.28**.
