# Runbook: user offboarding

1. Disable the account **within 1 hour** of the client's request.
2. Reset the password and revoke all sessions and MFA methods.
3. Convert the mailbox to shared and give access to the person the client names.
4. Collect the device; wipe it only after the client confirms nothing else is needed.
5. Remove the licence at the end of the month.
