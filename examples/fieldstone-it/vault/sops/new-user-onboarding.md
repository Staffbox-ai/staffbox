# Runbook: new user onboarding

Needs at least **3 business days** notice from the client.

1. Create the Microsoft 365 account and add the licence the client's note says.
2. Enrol MFA before the first login.
3. Prepare the device from stock or order it ([[quote-a-hardware-line]]).
4. Add the user to the client's shared mailboxes and groups listed in the client note.
5. Send the welcome email with first-login steps to the user's manager, never to a personal address.
