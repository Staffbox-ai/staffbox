# Runbook: MFA lockout

1. **Verify identity first: call the user back on the phone number in the client note.** Never reset on the strength of an email or an inbound call alone.
2. Remove the old MFA method and issue a temporary access pass valid for 1 hour.
3. If the user is an executive, tell the service director at once ([[approvals]]).
4. Log the reset in the ticket.
